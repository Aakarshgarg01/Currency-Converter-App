# 💱 Currency Converter App

A simple and responsive **Currency Converter** built using **HTML, CSS, and JavaScript**.
This app allows users to convert between different currencies in real-time using live exchange rates.



## 🚀 Features

* Convert between multiple currencies instantly
* User-friendly and responsive design
* Clean UI with simple input fields
* Fetches **real-time exchange rates**
* Works on both desktop and mobile devices



## 🛠️ Tech Stack

* **HTML5** – Structure of the app
* **CSS3** – Styling and layout
* **JavaScript (Vanilla JS)** – Functionality and API integration
